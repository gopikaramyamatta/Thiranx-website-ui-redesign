# Website UI Redesign Project

## Project Overview
Redesigned a local library website to improve usability and mobile experience.

## Heuristic Evaluation (Usability Problems Found)
| Problem | Severity |
|---------|----------|
| Search bar hidden | High |
| Not mobile friendly | High |
| Inconsistent buttons | Medium |
| Too much text | Medium |
| No confirmation dialogs | Low |

## Style Guide
- **Colors:** Blue (#2C5F8A), Light Gray (#F5F5F5), Orange for buttons (#FF8C42)
- **Fonts:** Arial Bold (headings), Arial Regular (body)
- **Buttons:** Round corners, orange background

## Mockups (Desktop vs Mobile)

### Desktop
- Header with logo + navigation
- Prominent search bar
- 3-column layout for content
- Footer with contact info

### Mobile
- Hamburger menu (☰)
- Same content stacked vertically (1 column)
- Larger touch targets (44x44px)

## Before vs After
**Before:** Cluttered, broken on phone, confusing navigation
**After:** Clean layout, responsive design, consistent buttons

## What I Learned
- Visual hierarchy helps users find important things first
- Mobile design requires rethinking layout (not just shrinking)
- Consistent components create professional look

## Tools Used
- Heuristic evaluation (Nielsen's principles)
- Style guide creation
- Responsive design planning
